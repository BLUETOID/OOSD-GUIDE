Q1 • 7 Marks Explain the concept of encapsulation and information hiding. How do these principles ensure system security and maintainability? Provide a UML example to demonstrate these principles.

1. Concept of Encapsulation and Information Hiding

Encapsulation: The programming language mechanism that packages data members (state) and member functions (behavior) into a cohesive, self-contained physical structure (the class).

Information Hiding: The design principle of concealing the internal representation details, storage data structures, and algorithms of an object from external entities, exposing only an abstract, well-defined public interface.

2. How Encapsulation and Information Hiding Ensure System Security & Maintainability

Engineering GoalMechanismImpact on the System
System Security (Invariant Integrity)Private data specifier (-) and validating public methods.Prevents external corruption of internal state (e.g. setting negative account balances, illegal state transitions).
Maintainability (Loose Coupling)Public interface decoupling from private implementation.Internal data structures (e.g. replacing an array with a hash map) can be changed without modifying external calling code.
Bug LocalizationEncapsulated boundary barriers.Restricts debugging search space to the declaring class methods rather than scanning the entire global codebase.

4. Compilable C++ Implementation

#include <iostream>
#include <string>

class BankAccount {
private:
    int accountNumber;
    double balance;

public:
    BankAccount(int accNo, double initialDeposit) 
        : accountNumber(accNo), balance(initialDeposit > 0 ? initialDeposit : 0.0) {}

    bool deposit(double amount) {
        if (amount <= 0.0) return false;
        balance += amount;
        return true;
    }

    bool withdraw(double amount, const std::string& pin) {
        if (amount <= 0.0 || amount > balance || pin != "1234") return false;
        balance -= amount;
        return true;
    }

    double getBalance() const { return balance; }
};

int main() {
    BankAccount account(1001, 5000.0);
    account.deposit(1500.0);
    account.withdraw(2000.0, "1234");
    std::cout << "Final Verified Balance: $" << account.getBalance() << "\n";
    return 0;
}

Q4 • 7 Marks Create a C++ program that uses a callback mechanism. Explain how callbacks are implemented in C++ using function pointers or lambda expressions.

1. Callback Architecture in C++

A callback is an executable code block passed as an argument to another function, enabling the receiving routine to invoke it when an event or asynchronous task completes. In modern C++, callbacks are implemented via Function Pointers, std::function wrappers, and Lambda Expressions.

2. Compilable C++ Callback Implementation

#include <iostream>
#include <functional>
#include <string>

// Asynchronous Service using std::function callback
void downloadFileAsync(const std::string& url, std::function<void(bool, int)> onComplete) {
    std::cout << "Starting download from: " << url << "\n";
    bool success = true;
    int bytesDownloaded = 4096;
    onComplete(success, bytesDownloaded);
}

int main() {
    downloadFileAsync("https://cdn.example.com/update.bin", [](bool status, int bytes) {
        if (status) {
            std::cout << "[Callback Executed] Success! Received " << bytes << " bytes.\n";
        } else {
            std::cout << "[Callback Executed] Download Failed!\n";
        }
    });
    return 0;
}

Q5 • 7 Marks Write a C++ program to implement operator overloading for matrix addition and subtraction. Include detailed comments on the implementation.

1. Matrix Operator Overloading Principles

Operator overloading allows user-defined types (like a Matrix class) to use standard mathematical operators (+, -) with natural algebraic syntax.

2. Compilable C++ Matrix Program

#include <iostream>
#include <vector>

class Matrix {
private:
    int rows, cols;
    std::vector<std::vector<int>> data;

public:
    Matrix(int r, int c) : rows(r), cols(c), data(r, std::vector<int>(c, 0)) {}

    void setElement(int r, int c, int val) { data[r][c] = val; }

    Matrix operator+(const Matrix& other) const {
        Matrix result(rows, cols);
        for (int i = 0; i < rows; ++i) {
            for (int j = 0; j < cols; ++j) {
                result.data[i][j] = this->data[i][j] + other.data[i][j];
            }
        }
        return result;
    }

    Matrix operator-(const Matrix& other) const {
        Matrix result(rows, cols);
        for (int i = 0; i < rows; ++i) {
            for (int j = 0; j < cols; ++j) {
                result.data[i][j] = this->data[i][j] - other.data[i][j];
            }
        }
        return result;
    }

    void display() const {
        for (int i = 0; i < rows; ++i) {
            for (int j = 0; j < cols; ++j) {
                std::cout << data[i][j] << "\t";
            }
            std::cout << "\n";
        }
    }
};

int main() {
    Matrix m1(2, 2), m2(2, 2);
    m1.setElement(0,0, 6); m1.setElement(0,1, 8);
    m1.setElement(1,0, 4); m1.setElement(1,1, 9);

    m2.setElement(0,0, 2); m2.setElement(0,1, 3);
    m2.setElement(1,0, 1); m2.setElement(1,1, 4);

    Matrix addRes = m1 + m2;
    Matrix subRes = m1 - m2;

    std::cout << "--- Matrix Addition (m1 + m2) ---\n";
    addRes.display();
    std::cout << "--- Matrix Subtraction (m1 - m2) ---\n";
    subRes.display();
    return 0;
}

3. C++ Polymorphic Implementation

#include <iostream>
#include <vector>
#include <memory>

class CourseMaterial {
public:
    virtual void renderMaterial() const = 0;
    virtual ~CourseMaterial() = default;
};

class VideoLecture : public CourseMaterial {
public:
    void renderMaterial() const override {
        std::cout << "[Video Player] Streaming 1080p Lecture Video...\n";
    }
};

class InteractiveQuiz : public CourseMaterial {
public:
    void renderMaterial() const override {
        std::cout << "[Quiz Engine] Initializing 10 Multiple-Choice Questions...\n";
    }
};

int main() {
    std::vector<std::unique_ptr<CourseMaterial>> materials;
    materials.push_back(std::make_unique<VideoLecture>());
    materials.push_back(std::make_unique<InteractiveQuiz>());

    for (const auto& mat : materials) {
        mat->renderMaterial(); // Dynamic Polymorphic Dispatch
    }
    return 0;
}

inline int inlineSquare(int x) {

Q14 • 7 Marks Explain the concept of static data members and functions. Write a C++ program to track the number of objects created for a class.

1. Static Data Members and Static Functions

  • Static Data Member: A single shared memory variable allocated in the static data segment rather than inside each object instance. Must be explicitly defined in file scope.
  • Static Member Function: A class-scope function callable without an object instance (Class::func()). Cannot access non-static data or the this pointer.

2. Object Counter Tracking Program

#include <iostream>

class InstanceTracker {
private:
    static int objectCount; // Shared static counter
    int id;

public:
    InstanceTracker() {
        objectCount++;
        id = objectCount;
        std::cout << "[Constructed] Object #" << id << " created. Total active: " << objectCount << "\n";
    }

    ~InstanceTracker() {
        objectCount--;
        std::cout << "[Destroyed] Object #" << id << " destroyed. Remaining active: " << objectCount << "\n";
    }

    static int getActiveCount() {
        return objectCount; // Static function accessing static data
    }
};

// Global definition of static member variable
int InstanceTracker::objectCount = 0;

int main() {
    std::cout << "Initial Count: " << InstanceTracker::getActiveCount() << "\n";
    {
        InstanceTracker obj1;
        InstanceTracker obj2;
        std::cout << "Current Active Count: " << InstanceTracker::getActiveCount() << "\n";
    } // obj1 and obj2 destroyed here
    std::cout << "Final Count: " << InstanceTracker::getActiveCount() << "\n";
    return 0;
}

Q15 • 7 Marks Develop a C++ program to implement hybrid inheritance. Explain how ambiguity is resolved using virtual base classes.

1. Hybrid Inheritance Ambiguity & The Diamond Problem

Hybrid inheritance occurs when multilevel, multiple, and hierarchical inheritance patterns combine. When two derived classes inherit from a common base class and a fourth class inherits from both derived classes, two duplicate copies of the base class data exist in memory, triggering compilation errors.

Resolution: Virtual Base Classes (virtual public Base) ensure a single shared instance of the root base class.

2. Compilable C++ Hybrid Inheritance Solution

#include <iostream>

class Student {
public:
    int rollNumber;
    Student(int r = 0) : rollNumber(r) {}
};

// Virtual Base Class Inheritance
class AcademicTest : virtual public Student {
public:
    double part1, part2;
    AcademicTest(int r, double p1, double p2) : Student(r), part1(p1), part2(p2) {}
};

class SportsScore : virtual public Student {
public:
    double sportsScore;
    SportsScore(int r, double s) : Student(r), sportsScore(s) {}
};

class FinalResult : public AcademicTest, public SportsScore {
public:
    FinalResult(int r, double p1, double p2, double s)
        : Student(r), AcademicTest(r, p1, p2), SportsScore(r, s) {}

    void display() const {
        double total = part1 + part2 + sportsScore;
        std::cout << "Roll No: " << rollNumber << " | Total Composite Score: " << total << "\n";
    }
};

int main() {
    FinalResult student1(101, 45.0, 42.0, 9.5);
    student1.display();
    return 0;
}

Q21 • 7 Marks Discuss the concept of encapsulation with suitable example.

1. Detailed Concept of Encapsulation

Encapsulation binds data attributes together with member functions in a single structural class unit, preventing arbitrary external tampering by enforcing strict visibility barriers (private, protected, public).

2. Compilable C++ Demonstration

#include <iostream>

class TemperatureSensor {
private:
    double celsius; // Private encapsulated state

public:
    TemperatureSensor() : celsius(0.0) {}

    bool setTemperature(double temp) {
        if (temp < -273.15) return false; // Absolute zero invariant validation
        celsius = temp;
        return true;

Q29 • 7 Marks Design a class using C++ to create a singly linked list.

1. Singly Linked List Class Design in C++

#include <iostream>

class SinglyLinkedList {
private:
    struct Node {
        int data;
        Node* next;
        Node(int val) : data(val), next(nullptr) {}
    };
    Node* head;

public:
    SinglyLinkedList() : head(nullptr) {}

    void insert(int val) {
        Node* newNode = new Node(val);
        if (!head) {
            head = newNode;
            return;
        }
        Node* temp = head;
        while (temp->next) temp = temp->next;
        temp->next = newNode;
    }

    void display() const {
        Node* temp = head;
        while (temp) {
            std::cout << temp->data << " -> ";
            temp = temp->next;
        }
        std::cout << "NULL\n";
    }

    ~SinglyLinkedList() {
        Node* curr = head;
        while (curr) {
            Node* nextNode = curr->next;
            delete curr;
            curr = nextNode;
        }
    }
};

int main() {
    SinglyLinkedList list;
    list.insert(10);
    list.insert(20);
    list.insert(30);
    std::cout << "Linked List: ";
    list.display();
    return 0;
}
Execution Output
Linked List: 10 -> 20 -> 30 -> NULL

Q67 • 7 Marks Differentiate overloading and overriding. Write a program to overload &amp;quot;+&amp;quot; operator using friend function to concatenate two strings.

1. Overloading vs Overriding & String Concatenation '+' using Friend Function

#include <iostream>
#include <cstring>

class CustomString {
private:
    char* str;

public:
    CustomString(const char* s = "") {
        str = new char[std::strlen(s) + 1];
        std::strcpy(str, s);
    }

    CustomString(const CustomString& other) {
        str = new char[std::strlen(other.str) + 1];
        std::strcpy(str, other.str);
    }

    friend CustomString operator+(const CustomString& s1, const CustomString& s2);

    void print() const { std::cout << str << "\n"; }

    ~CustomString() { delete[] str; }
};

CustomString operator+(const CustomString& s1, const CustomString& s2) {
    char* buffer = new char[std::strlen(s1.str) + std::strlen(s2.str) + 1];
    std::strcpy(buffer, s1.str);
    std::strcat(buffer, s2.str);
    CustomString result(buffer);
    delete[] buffer;
    return result;
}

int main() {
    CustomString str1("Object Oriented ");
    CustomString str2("Design with C++");
    CustomString str3 = str1 + str2;
    std::cout << "Concatenated String: ";
    str3.print();
    return 0;
}

Q68 • 7 Marks What does the inheritance mean in C++? What is containership? How does it differ from inheritance? Explain. Write a program to demonstrate how ambiguity is avoided in a single inheritance using scope resolution operators.

1. Inheritance vs Containership (Composition)

  • Inheritance (Is-A): A derived class acquires methods and attributes from a base class (e.g. Dog is-a Animal).
  • Containership (Has-A / Composition): A class contains an instance of another class as a member variable (e.g. Car has-a Engine).

2. Avoiding Ambiguity in Single Inheritance via Scope Resolution

#include <iostream>

class BaseClass {
public:
    void showMessage() {
        std::cout << "Message from BaseClass\n";
    }
};

class DerivedClass : public BaseClass {
public:
    // Hides BaseClass::showMessage()
    void showMessage() {
        std::cout << "Message from DerivedClass\n";
    }
};

int main() {
    DerivedClass d;
    d.showMessage();             // Calls DerivedClass::showMessage()
    d.BaseClass::showMessage();  // Disambiguates and calls BaseClass explicitly
    return 0;
}

Q69 • 7 Marks What is Pointer in C++? Define const pointers. What is the usage of the pointer in C++? What is the size of a void pointer in C? Demonstrate it.

1. Pointers in C++: Const Pointers & Void Pointer Size

  • Pointer to Constant (const int* ptr): Data cannot be modified through the pointer; the pointer address can change.
  • Constant Pointer (int* const ptr): Pointer address is fixed; the underlying data can be modified.
  • Constant Pointer to Constant (const int* const ptr): Neither the address nor the data can be modified.
  • Size of Void Pointer (void*): Equal to the machine architecture word size (8 bytes on 64-bit OS, 4 bytes on 32-bit OS).
