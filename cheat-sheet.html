2. 1-Liner Master Definitions (High-Scoring Viva & 2-Markers)

Term Exact Exam Definition
Encapsulation The packaging mechanism that encloses data members and member functions within a class container.
Information Hiding The design principle of restricting direct outside access to internal object representation using access specifiers.
Dynamic Binding The runtime mechanism where a virtual function call is resolved dynamically via a VTable lookup at execution time.
Name Mangling The compiler technique of encoding function parameter types into symbol names to support function overloading.
RAII Principle Resource Acquisition Is Initialization: binding resource lifetime (memory, files) strictly to object lifetime via constructors and destructors.
Abstract Class A class containing at least one pure virtual function (= 0) that serves as an uninstantiable interface contract.
Virtual Base Class A base class inherited with the virtual keyword to guarantee a single shared instance in diamond inheritance hierarchies.
Object Identity The unique property that distinguishes an object from all others based on its distinct physical memory address, irrespective of state equality.

3. Master Comparison Matrices

3.1 Preprocessor Macro vs. Inline Function

Feature Preprocessor Macro (#define) Inline Function (inline)
Evaluation StagePreprocessor (Blind text substitution)Compiler (Generated machine code expansion)
Type CheckingNone (Prone to runtime errors)Strictly enforced by compiler
Side EffectsHazardous (e.g. SQR(x++) increments twice)Safe (Arguments evaluated once)
DebuggingInvisible in GDB / debuggersFull symbol table and breakpoints available

3.2 Shallow Copy vs. Deep Copy

Dimension Shallow Copy (Default Memberwise) Deep Copy (Custom Copy Constructor)
Pointer MembersCopies raw memory address; both point to same bufferAllocates distinct heap memory and copies data
Destruction SafetyCauses Double-Free Crash on destructionCompletely safe; each object frees its own buffer
RequirementSufficient for POD (Plain Old Data) classesMandatory for classes managing dynamic heap memory

3.3 Function Overloading vs. Function Overriding

Comparison Function Overloading (Compile-Time) Function Overriding (Run-Time)
ScopeOccurs within the same class/scopeOccurs across Base and Derived classes
SignatureMust differ in parameter count or parameter typesMust match name, parameters, and return type exactly
KeywordNo special keyword requiredRequires virtual in base class
BindingEarly static binding at compile-timeLate dynamic binding via VTable/VPtr

6. C++ Language Constraints Checklist

Operators that CANNOT be Overloaded in C++:
  1. :: (Scope Resolution Operator)
  2. . (Member Access Dot Operator)
  3. .* (Pointer-to-Member Operator)
  4. ?: (Ternary Conditional Operator)
  5. sizeof (Size Operator)
  6. typeid (RTTI Type Identification Operator)
Default Arguments Rules:
  • Must be supplied strictly from right to left in the parameter list.
  • Must be declared in the function prototype/declaration, not repeated in the definition.

7. Top 10 Exam Traps to Avoid

# Common Student Mistake Correct Exam Approach & Rule
1 Forgetting virtual on Base Destructors Always write virtual ~Base() {} on polymorphic base classes to prevent memory leaks during delete basePtr;.
2 Forgetting global definition for static data Declaring static int count; inside a class requires int ClassName::count = 0; in global file scope.
3 Using this in static member functions Static member functions do not receive an implicit this pointer.
4 Overloading on return type alone Functions cannot be overloaded based solely on different return types.
5 Drawing regular arrows instead of hollow triangles for Inheritance UML Generalization requires a solid line with a hollow triangular arrowhead (──▷), not a stick arrow.
6 Omitting underline on Object Diagram names Object names in UML Object Diagrams must always be underlined (e.g. cust1 : Customer).
7 Confusing <<include>> and <<extend>> <<include>> is unconditional and mandatory; <<extend>> is optional and conditional.
8 Assuming Friendship is inherited or transitive Friendship in C++ is neither inherited nor transitive.
9 Confusing Aggregation with Composition Aggregation (◇──) parts survive container destruction; Composition (◆──) parts are destroyed with the container.
10 Not freeing dynamic memory in custom Destructors Every new or new[] in a constructor must have a matching delete or delete[] in the destructor.
